Wedding Album Selector

Photo Source

Point this at the folder your OneDrive-synced wedding photos live in. Sub-folders are scanned too.

Clear Library

Forgets every photo and page this app has cataloged, so you can scan a different folder from scratch. Your real photo files are never touched by this — it only clears this app's own record in data/state.json.

OneDrive Integration

One-time setup: register a free app with Microsoft so this app can sign in and browse your OneDrive photos directly (needed because OneDrive's own web page can't be dragged from). See GETTING_STARTED.md for the exact steps.

Version History

A restore point is saved automatically before scanning a new folder, rescanning, or clearing the library — so any of those can be undone. Restoring one also saves your current state as a restore point first, so restoring is itself undoable.

Layout:

Drag the divider lines on the page below to resize how much space each photo gets. You can drag a photo file straight from File Explorer onto any slot below.

Set a page count above to start designing your album.

Summary

A. For the Photographer

Copies original, full-resolution files into numbered page folders plus an index.txt. Each time you click export, a new, separately-named folder is created inside the location below — nothing from a previous export gets overwritten.

B. For Yourself

A single PDF preview of the album, matching your layout. Not print resolution.

Previous Exports

Every "Export Original Files Folder" run you've done. Delete any you no longer need — this removes that exported copy folder from disk, not your original photos.
